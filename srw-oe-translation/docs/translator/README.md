# Materiały translatorskie — SRW OE EN

Pochodzą z pakietu EN3.zip (Tłumacz, 2026-10-16). Służą jako referencja dla ciągłości tłumaczenia.

## Pliki

| Plik                 | Opis                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| `glossary.json`      | Słownik postaci, serii, terminów (EN z oficjalnych wydań SRW)        |
| `glossary_extra.tsv` | Dodatkowy słownik: mechy, bronie, nowe terminy (JP<TAB>EN<TAB>uwaga) |
| `voice_cards.md`     | Karty głosu postaci — jak mówi każda postać, tiki, zwroty, rejestr   |
| `STYLE.md`           | Przewodnik stylu (obowiązuje wszystkich tłumaczy)                    |
| `WSTEP.md`           | Status projektu z perspektywy Tłumacza (po polsku)                   |
| `briefy/`            | Instrukcje zadań (scene, quotes, views, mecha, bible)                |
| `bible/`             | Streszczenia odcinków po angielsku (epizod-00 … epizod-34)           |

## Uwagi

- Ścieżki wewnątrz plików (np. `/home/claude/work/…`) dotyczą środowiska Tłumacza — nie są przenośne.
- `glossary.json` jest źródłem prawdy dla nazw w grze.
- `glossary_extra.tsv` jest przyrostowy — nowe terminy dopisuje się na końcu.
