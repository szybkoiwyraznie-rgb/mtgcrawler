# Czytanki SRW Y — częściowy snapshot PL

Wygenerowano z odtworzonego korpusu S6, indeksu źródłowego i zaakceptowanych planów importu (w tym wydaniu zaakceptowanych wierszy PL: 29873).
To wydanie **nie jest pełnym polskim tłumaczeniem**: obejmuje tylko dostępne zaakceptowane teksty PL.
Wydanie zawiera wyłącznie polski tekst. Braki są wyłącznie jawnymi polskimi znacznikami `[BRAK PL]` — bez japońskiego źródła i bez angielskiego odniesienia.

Czytanki scen obejmują pliki zawierające co najmniej jedną przetłumaczoną kwestię wybranego wariantu; pozostałe kwestie tych scen oznaczono jako braki.
Cytaty bitewne pominięto. Wiersze scen bez japońskiego źródła są wykazane w recepcie.
Unikalne użyte adresy: 11597. Braki tekstu/powiązań: 6670.

Protagonista: domyślnie mężczyzna; wariant żeński tylko w misjach, w których nie ma wariantu męskiego.
Rozdziały pochodzą z danych misji. Deployment to uczestnicy wymienieni w presetach, bez momentów wejścia.
Przy pierwszym wystąpieniu podano potwierdzone powiązanie biografii/opisu
z 11 assetów właścicielskich lub oznaczono brak wpisu; brakująca polska proza to `[BRAK PL]`.
Encyklopedia zawiera kompletny polski indeks haseł z kluczami Shared Data.
Nierozwiązane referencje presetów: 0 (było 91); 109 bundli z `SRW_Y_PRESETY.zip` rozwiązało 88 pozostawiając 3, a 3 bundli z `SRW_Y_PRESETY3.zip` zamknęły ostatnie 3 — razem 91 po dokładnej parze (CAB, PathID), grafy zdarzeń 0.
Parametry są bazowe; katalog zawiera też warianty techniczne i wrogów, nie tylko roster gracza.
Brak twierdzenia o stanie aktualnie zainstalowanej gry, o chronologii wywołań zdarzeń
ani o pełnej przebudowie patcha.
